Offline Backup Viewer

Read-only — browsing a backup never sends your data anywhere, and nothing here ever writes back to the live app (so "mark uploaded" isn't available offline). Load a backup JSON file (from the app's Admin tab → "Export all data as JSON", or an hourly automated one if that's set up — see backupFirestoreToDrive.gs in the repo) if the live site/Firestore is ever unreachable. Just double-click this file to open it in a browser — no server or install needed. The Questions tab has the same filters as the live Question Bank tab, and every question — not just locked/uploaded ones — can be previewed and downloaded as an image, so a draft or unreviewed question is still usable in a pinch. Previewing/downloading needs internet access (to load MathJax/html2canvas from a CDN) — every other part of this page works fully offline.
